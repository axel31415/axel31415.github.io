Données collectées

Quand vous faites le diagnostic, je collecte vos réponses au questionnaire et les coordonnées demandées dans le formulaire, au minimum votre adresse email pour vous envoyer le résultat. Ce site n'utilise pas de cookie publicitaire.

Pourquoi ces données

Pour calculer votre score, vous envoyer votre résultat par email, puis vous proposer un échange. Ce traitement repose sur votre consentement, donné en remplissant le formulaire. Vous pouvez le retirer à tout moment en m'écrivant.

Qui traite ces données

Le site est hébergé par GitHub Pages (GitHub, Inc., États-Unis), qui peut enregistrer l'adresse IP des visiteurs pour la sécurité du service. Le formulaire est hébergé par Tally. Les réponses transitent par Make et Google (Sheets, Gmail, Agenda). Tally est établi dans l'Union européenne et Make en République tchèque. Google peut traiter des données hors de l'Union européenne, dans le cadre des garanties prévues par le RGPD.

Durée de conservation

Trois ans après notre dernier contact, sauf si vous demandez leur suppression avant.

Vos droits

Vous pouvez demander l'accès, la rectification ou la suppression de vos données en écrivant à axelbrunon@gmail.com. Vous pouvez aussi saisir la CNIL (cnil.fr).
